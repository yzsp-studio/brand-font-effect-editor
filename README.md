## 🇬🇧 English

This skill runs a fixed six-step flow for font-effect replacement. It receives reference image 1 and identifies the font in it, then receives target image 2 and identifies its font — both images are understood before anything changes. Step 5 presents a single selection card so the user confirms all replacement parameters in one pass instead of being asked back and forth. Step 6 reads the target image dimensions so the replaced type keeps its proportions against the original. Every step has a defined input and output, and the result traces back to the reference image.

### ✨ What it does

- Steps 1-2: receive reference image 1 and identify the font inside it
- Steps 3-4: receive target image 2 and identify its font before changing anything
- Step 5: a one-shot selection card confirms all replacement parameters in a single pass
- Step 6: reads target image dimensions so the new type matches the original proportions
- Fixed six-step flow where each step has a defined input and output
- Results trace back to the reference image, so the basis for the swap is explicit
